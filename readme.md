# Asante Twi Standard Dictionary

This repository contains the source translations for **Asante Twi Standard** variant.

## Locale Identifier

`twi_GH@asante-standard`

## Contents

- `src/twi_GH@asante-standard.po` - Main translation file
- `glossary.csv` - Master term list with translations

## Contributing

1. Edit `src/twi_GH@asante-standard.po` or `glossary.csv`
2. Run `./scripts/validate.sh` to check syntax
3. Submit a pull request

## Validation

```bash
./scripts/validate.sh
```
